# 高槻駅周辺グルメマップ

このフォルダは静的Webサイトとしてそのまま公開できます。

## 主な機能

- 高槻駅周辺の214店舗を掲載
- 店名・メニュー・ジャンルで検索
- カテゴリー・予算で絞り込み
- 予算順・駅から近い順で並び替え
- 現在地の取得
- 店舗を地図上に表示
- 現在地から店舗までの直線距離を表示
- Google Mapsで経路を確認

## 公開方法

### GitHub Pages
1. GitHubで新しいリポジトリを作成
2. このフォルダ内の `index.html` と `.nojekyll` をアップロード
3. リポジトリの Settings → Pages を開く
4. Branch を `main` / `root` に設定
5. 表示されたURLをスマートフォンで開く

位置情報機能を使うため、公開URLはHTTPSで利用してください。

### その他の静的ホスティング
Netlify、Cloudflare Pages、Vercelなどでも `index.html` を配置するだけで公開できます。

## 注意
店舗位置の検索にはOpenStreetMap/Nominatimを利用しています。短時間に多数の店舗を一括検索する実装ではなく、ユーザーが「地図で見る」を押した店舗を都度検索する方式です。
